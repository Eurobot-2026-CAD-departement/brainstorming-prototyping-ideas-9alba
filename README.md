# Brainstorming & prototyping — 9alba

One of the **design ideas** explored in the brainstorming/prototyping phase of Eurobot 2026, named after its designer/idea (`9alba`).

## Contents
- `9alba.SLDASM` — full assembly (base, profile 20x20, guiding rails, ball caster + support, nuts)
- `rail dimensionned 9alba*` — rail variants for the elevator and the "pertruder" (`mjarfa`) mechanisms
- `hazel nut crate 9alba.SLDPRT` — crate model used for testing
- `mjarfa dhia adapted/` — adapted `mjarfa` mechanism
- `piece util/` — reusable parts
